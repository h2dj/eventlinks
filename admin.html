🔗 링크 편집기

아래에서 링크를 자유롭게 수정한 뒤, 다운로드 버튼으로 받은 파일을 GitHub의 js/links-data.js 파일에 덮어쓰면 실제 사이트에 반영됩니다.

  1. 아래 목록에서 아이콘·제목·URL을 수정하거나, 링크 추가/삭제/순서 변경
  2. 오른쪽(또는 아래) 미리보기에서 실제 버튼 모양 확인
  3. 파일 다운로드 버튼 클릭 → links-data.js 파일 저장
  4. GitHub 저장소 → js/links-data.js 열기 → 연필(✏️) 아이콘 클릭
  5. 기존 내용을 지우고, 다운로드한 파일 내용을 붙여넣은 뒤 커밋(저장)

⚠️ 이 페이지 자체는 미리보기/편집 도구이며, 여기서 수정한 내용이 자동으로 실제 사이트에 올라가지는 않습니다. 위 4~5번 단계까지 마쳐야 실제로 반영됩니다. 작업 중인 내용은 이 브라우저에 임시 저장되니, 다시 열어도 이어서 편집할 수 있습니다.
